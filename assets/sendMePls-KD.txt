Project Overview: SendMePls
SendMePls is a comprehensive Laravel-based delivery and e-commerce platform designed for managing shopping orders, delivery agents, payments, and logistics. It enables customers to place shopping orders, assigns delivery agents for fulfillment, handles real-time tracking, payment approvals, and admin oversight. The system supports end-to-end order lifecycle management, including agent onboarding, vehicle assignments, invoice uploads, refunds, and integrations with third-party services for payments and communications.

Key Technologies and Architecture
Backend Framework: Laravel 12 (PHP 8.2+), with Eloquent ORM for database interactions, Sanctum for API authentication, and Reverb for WebSocket-based real-time events.
Database: MySQL with migrations and seeders; Redis for caching, queues, and session management.
Frontend: Blade templates with Tailwind CSS for responsive UI; Vite for asset bundling; Axios for API calls; Laravel Echo with Pusher for real-time notifications and updates.
Third-Party Integrations:
PayCentral: Card allocation, loading, balance checks, and fund transfers for agent payments.
Ozow: Payout API for bank transfers.
Agora: Token generation for video/audio calls between agents and customers.
Twilio: SMS notifications.
Google API Client: Likely for maps, geolocation, or other services.
Pusher: Real-time broadcasting for order updates, payment requests, and notifications.
Real-Time Features: WebSockets for live order tracking, payment approvals, and agent-customer interactions.
Job Processing: Laravel queues with Redis for background tasks (e.g., notifications, invoice processing).
Testing: PHPUnit for unit and feature tests; Postman collections for API testing.
Deployment: PM2 (via ecosystem.config.js) for process management; Workerman for additional WebSocket handling.
Security: Encryption helpers (AES), hashed passwords, and secure file uploads.
Other Tools: PhpSpreadsheet for Excel exports, Predis for Redis interactions.
Key Features and Deliverables
The platform is modular, with extensive documentation in the docs folder covering implementations, APIs, and testing. Below are the core deliverables grouped by functionality:

Delivery Agent Management:

Onboarding and approval/rejection workflow with document verification (ID, driving license, vehicle docs).
Vehicle assignment (company-owned or self-owned) with type and status tracking.
Bank details integration for payouts via Ozow API.
Card allocation and fund loading via PayCentral for agent earnings.
Profile management, status updates, and exportable reports (CSV/Excel).
Real-time notifications for approvals/rejections.
Order Management:

Shopping Orders: Customer-initiated orders with multi-shop support, item pricing, VAT calculations, discounts, and budget tracking.
Active Orders: Real-time event broadcasting for order status updates (e.g., agent assignment, shop visits).
Cancellation System: Agent/customer-initiated cancellations with reason tracking and API endpoints.
Delivery Confirmation: Mark-as-delivered API with agent feedback and notifications.
Invoice Management: Upload, verification, and status tracking with WebSocket updates for real-time admin review.
Payment and Financial Systems:

Payment approval flows: Agents request customer approval for purchases; handles budget exceedances with extra payment links.
Refund Logic: Automated refunds based on order cancellations or issues, with duplicate prevention.
Fund Transfers: Simplified card-to-card transfers via PayCentral.
VAT and Discount Calculations: Dynamic pricing with budget carryover and variance approvals.
Admin Panel and Oversight:

Comprehensive dashboard for managing agents, orders, and invoices.
Order flagging, priority assignment, and manual agent assignments.
Admin logs for tracking actions (e.g., reviews, overrides).
Export functionalities for agents and orders.
Real-time monitoring of order statuses and agent activities.
Real-Time and Communication Features:

WebSocket events for order updates, payment requests, and invoice status.
FCM (Firebase Cloud Messaging) notifications for mobile apps.
Agora integration for video calls during deliveries.
Pusher-based broadcasting for live UI updates.
API Ecosystem:

RESTful APIs for all core functionalities (e.g., agent management, order processing, payments).
Versioned API structure (e.g., Api/V1/) with services for modularity.
Postman collections for testing and documentation.
Additional Modules:

Prescription handling for medical deliveries.
Shop validation APIs (e.g., distance checks).
Parallel queue processing for high-load scenarios.
Comprehensive testing guides and implementation summaries for maintainability.
Project Scale and Complexity
Codebase Size: Large-scale application with ~100+ models, controllers, services, events, and migrations.
Database Tables: Extensive schema for orders, agents, vehicles, payments, invoices, and logs (e.g., 20+ tables with relationships).
Performance Optimizations: Queues for async processing, caching for API responses (e.g., bank lists), and indexed queries for filtering.
Error Handling and Logging: Robust exception handling, Log facade usage, and retry mechanisms (e.g., for database deadlocks).
Compliance and Security: Encrypted sensitive data (e.g., personal IDs), secure file storage, and validation rules.
