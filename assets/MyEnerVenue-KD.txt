Project Analysis: EnerVenue HR Management System
Based on the codebase analysis, this is a comprehensive Human Resources Management System (HRMS) built for EnerVenue, a company managing employees in the US and China. The system integrates with external services like TriNet (for HR operations) and Azure Translator for multilingual support. Below is a summary of the Key Deliverables (KD) – the core features and functionalities delivered in this project. This can be adapted for your CV under "Projects" or "Achievements" section.

Project Overview
Name: EnerVenue HRMS (Internal name: Phoenix)
Type: Web-based HR Management Application
Architecture: Full-stack Laravel application with real-time features
Technologies Used:
Backend: Laravel 11 (PHP 8.2), MySQL, Redis (caching/queues)
Frontend: Vite (build tool), Socket.io (real-time communication), Axios (HTTP client)
Key Libraries: Maatwebsite Excel (data import/export), Spatie Laravel Permission (RBAC), Intervention Image (image processing), Laravel Filemanager (file uploads), SAML2 (SSO authentication)
Integrations: TriNet API (HR services), Azure Translator (multilingual support), Brevo SMTP (email)
Deployment: PM2 for process management, supports dev/stage/production environments
Database: Relational MySQL with 60+ models for HR data (e.g., users, tasks, compensation, events)
Security: Role-based access control (HR, US HR, China HR, Managers), SAML2 SSO, encrypted data handling
Key Deliverables (Features Implemented)
Employee Lifecycle Management:

Full CRUD operations for employee profiles (personal details, addresses, emergency contacts, documents).
Bulk import/export via CSV/Excel for US and China employees, with validation and error handling.
Life event tracking: Leaves, separations, data changes, and applicable dates (e.g., hire dates, promotions).
Profile image uploads and document management with secure file storage.
Organization Structure & Hierarchy:

Management of departments, locations, company codes, and organizational charts.
Reporting structure visualization (my team, full org for US/China).
Export hierarchy to Excel for reporting.
Task & Workflow Management:

HR-driven task creation, delegation, and tracking with subtasks.
Employee task completion, progress marking, and undo functionality.
Automated task reminders via cron jobs and real-time notifications.
Compensation & Job Management:

Job code management (Radford integration), EEO codes, and compensation history tracking.
Additional payment codes and leave types/reasons.
Integration with TriNet for payroll and benefits synchronization.
Reporting & Analytics:

Dashboard with interactive charts (e.g., employee metrics).
Custom reports: Compensation history, department reports, task completion reports.
Export functionalities for Excel/CSV.
Communication & Engagement:

Announcements, FAQs, and common links with Azure-powered translation for multilingual support.
News management with permissions.
Real-time communication via Socket.io.
Notifications & Automation:

Automated IT emails for terminations and onboarding.
Cron jobs for employee syncing (TriNet), event handling, task reminders, and address updates.
Bulk news emails and configurable notification timings.
Contractor & External Management:

Separate module for contractor data import/export and management.
Security & Compliance:

SAML2-based SSO for secure login.
Role-based permissions (e.g., HR-only access to sensitive data).
Data encryption, session management, and audit trails.
Additional Features:

Multi-language support (English/Chinese) with real-time translation.
File uploads with Laravel Filemanager and image processing.
Meeting scheduling and policy document management.
API integrations for external HR services (TriNet production/sandbox modes).
Impact & Scale
Handles data for thousands of employees across US and China regions.
Supports complex HR workflows, reducing manual processes and improving compliance.
Real-time features enhance user experience for HR teams and employees.
Scalable architecture with queue-based processing for bulk operations.
